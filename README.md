# Amrutiya Jay — Personal Portfolio

Responsive portfolio built with HTML5, CSS3 and JavaScript.

## Files
- `index.html` — website structure and content
- `style.css` — responsive dark theme and layout
- `script.js` — mobile navigation and active section behavior

## Run locally
Open `index.html` in a browser. No build tools are required.

## Publish with GitHub Pages
1. Create a repository. For a user-site URL, name it `amrutiyajay7.github.io`.
2. Upload all files in this folder to the repository root.
3. Go to **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. After publishing, the user-site address should be `https://amrutiyajay7.github.io`.
